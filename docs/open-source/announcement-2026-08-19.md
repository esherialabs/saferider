# SafeRide is now open source

Publication date: 19 August 2026

SafeRide's public source repository is available at
`https://github.com/esherialabs/saferide`.

The repository brings the public-safe parts of the project together in one
place:

- the Android/Expo mobile application and ongoing iOS integration;
- the owned SafeRide API and local development infrastructure;
- the SafeRide website under `saferide.esheria.org`;
- public-safe on-device AI integration, model-training, export, and evaluation
  tooling; and
- architecture, security, governance, contribution, testing, coverage, SBOM,
  and reproducible-build documentation.

Code is licensed under Apache License 2.0. Included original documentation and
content are licensed under CC BY 4.0 where identified. Third-party assets,
models, datasets, and dependencies retain their own licenses.

The first open-source release is
`https://github.com/esherialabs/saferide/releases/tag/v0.5.8-open-source.1`.
The canonical Android download and checksum page remains
`https://saferide.esheria.org/download/`.

## Safety and privacy boundary

The public repository contains no survivor reports, evidence, credentials,
signing keys, production environment values, private partner material, or
restricted UNICEF records. SafeRide is not an emergency service and does not
replace a lawyer, safeguarding professional, or trusted support provider.

## Ways to participate

- Read the contribution guide and community roadmap.
- Open a public issue for a reproducible bug or documentation improvement.
- Review the public project roadmap and choose a `good first issue`.
- Report security or privacy concerns through the private process in
  `SECURITY.md`, never through a public issue.
