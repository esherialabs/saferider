# SafeRide project charter

## Mission

SafeRide develops privacy-preserving, survivor-centered tools for reporting,
evidence handling, trusted referrals, practical guidance, and aggregate safety
learning, especially in constrained-connectivity environments.

## Principles

- survivor agency, dignity, and explicit consent;
- data minimization, local-first operation, and fail-closed controls;
- truthful capability language and reviewable evidence;
- accessibility and meaningful human review;
- synthetic development and evaluation data by default; and
- public collaboration without exposing restricted people or records.

## Scope

The public project contains the Android-first mobile application, owned API and
local infrastructure, SafeRide website, public-safe model training/evaluation
code, schemas, synthetic/public-safe evidence, and reproducible release tools.

SafeRide is not an emergency service, legal representative, medical provider,
police service, UNICEF representative, or substitute for human safeguarding and
locally appropriate support.

## Open-source commitment

Public code is Apache-2.0. Enumerated original documentation, educational
content, and guardrails are CC-BY-4.0. Model and dataset terms are recorded
separately. Trademarks, real-person data, credentials, production secrets,
partner agreements, private security details, incident/risk registers, and
UNICEF submission records are outside the public grant.

The community may use, study, modify, and redistribute licensed material under
those terms. Project direction is managed through public issues, pull requests,
the project board, and the governance process in `GOVERNANCE.md`.

## Success and accountability

Success is measured by verified safe behavior, reproducible builds, useful
documentation, maintainable tests, and transparent limitations—not by
unsupported readiness claims. Field use, partner operation, production
deployment, store distribution, and UNICEF submission each require separate
authorization and evidence.
