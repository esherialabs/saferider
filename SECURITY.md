# Security policy

Do not report vulnerabilities, survivor information, evidence, exact private
locations, credentials, raw prompts/completions, or partner-confidential
material in a public issue.

Use GitHub's private vulnerability-reporting flow for this repository:

https://github.com/esherialabs/saferider/security/advisories/new

If that private flow is unavailable, stop and contact the known project lead
through an existing private organization channel. Do not create a public
fallback report. Include only the minimum synthetic reproduction, affected
revision, impact, and safe contact method. Never include real user data.

The public security contact is `sagini@esheria.ai`. The Android testing preview
is the only currently published app artifact; it is not a production or
survivor-facing release. Receipt and remediation SLAs remain to be formalized.
